# Tabasheer · طباشير

منصة شرح بالسبورة التفاعلية لمنهج البرمجة والذكاء الاصطناعي (الصف الثاني الثانوي · بكالوريا).

كل درس بيفتح كسبورة لا نهائية: إطارات الشرح (بأمثلتها وأسئلتها التفاعلية) + أدوات رسم وكتابة فوقها.

## التشغيل

```bash
npm install
npm run dev      # للتطوير: http://localhost:5173
npm run build    # نسخة نهائية في مجلد dist (افتحها بأي سيرفر static)
```

## إضافة درس جديد

1. اعمل مجلد `src/lessons/<id>/` وصدّر منه `LessonDef` (أقسام ← إطارات).
   - إطارات الشرح بتترسم كأنها على سبورة: `scene: true` ومكونات `src/sketch/Sketch.tsx`
     (Box, Arrow, Txt, Doodle, Note, Browser, Cylinder, Table…) بإحداثيات الإطار (عرض 1280).
     أي عنصر ليه `at={n}` بيترسم في دوره لما المدرس يضغط "التالي".
   - الكلام الكامل يتحط في `notes` للإطار (لوحة ملاحظات المدرس)، والسبورة يفضل عليها رسم وكلمات قليلة.
   - الأسئلة والتجارب التفاعلية من `src/kit/`.
2. سجّله في `src/lessons/index.ts`.
3. حط `board: '<id>'` للدرس في `src/curriculum.ts`.

الدروس القديمة (شرائح HTML) موجودة في `public/legacy/` وبتتفتح من نفس الصفحة الرئيسية لحد ما تتحول.

## الهوية

اللوجو في `public/brand/` (SVG للعلامة + PNG للشعار كامل بالاسم)، وكمكوّن في `src/brand/Logo.tsx`.
